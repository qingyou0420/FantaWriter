## 一、结论

**能合，有遗留。**

遗留清单（均不破红线；按影响排序）：

| # | 遗留 | 会不会让流程走歪 / 红线破 |
|---|---|---|
| 1 | **「本次把结局方向给 AI 参考」的显式勾选在排大纲主路径上是空的。** 大纲页勾选后，「生成大纲」（outline）和「续排本卷」（outline_next）两条路径页面层传了参数，但提示词组装函数不读取，勾了也不注入；「优化大纲」（polish_chapter_outline）虽然生效，但读的是旧字段 `outline.endingNote`，不是前提卡的「结局方向」——新项目结局方向写在前提卡里，勾了同样注入不到。 | 红线不破（失败方向是「永不注入」）。但作者以为给了 AI 收束方向，实际没给，属于「看起来做了、注入其实没做到」。不会写歪，只会收不拢且作者不知情。**建议合并后尽快接通。** |

| 5 | **默认落点尊重上次停留的 tab。** 只有初次打开或存的是旧默认（人物设定）时才强制落正文页 / 前提卡；上次停在大纲页就回大纲页。 | 合理的记忆行为，与文档「打开默认进正文页」字面略有出入，不算走歪，记录备查。 |

## 三、红线实锤

**结论：四类底牌在全部生成路径的组装产物里都搜不到，测试与人工复扫互相印证，未发现破口。**

1. **测试怎么锁的**（`src/lib/author-secrets.test.ts`）：构造一个把主题一句、结局方向、核心对抗、真相层四字段、「仅作者」暗线标题与备注、去向备注全部填上唯一标记串的项目（且故意把 `outline.endingNote` 也填成结局方向原文），然后：
   - 用 `assemble` 跑 15 个生成任务（正文、续写、改写、大纲、分卷大纲、续排、场景规划、场景正文、人物扩写 / 优化、背景扩写 / 优化、一键人设、单章润色、卷摘要），断言组装产物零命中；
   - 直接扫章节摘要与一致性检查两个 prompt builder；
   - 单独锁按拍契约与记忆包不含暗线标题 / 备注 / 去向备注；
   - 断言正文提示词不含「结局走向：」、契约禁令与前提正常注入、显式勾选时结局方向才出现；
   - 锁 pending 账本增量确认前不进记忆包、置顶条 22 章后仍注入。
2. **测试没扫到的路径，人工核过**：`optimize_settings`（注入人物与背景，但人物经 `assembleGeneral` 入口统一剥真相层、`formatCharacters` 白名单输出，无破口）；`learn_style` / `extract_canon` / `extract_skeleton`（只吃范文 / 原著采样文本，不读项目秘密字段）；`outline_vs_content`（路由只读本章大纲摘要与正文）。建议把 `optimize_settings` 补进测试清单（遗留 4）。
3. **注入函数逐个复扫**：`formatCharacterFull` 白名单不含 truth；`formatPlotThreads` / `selectPlotThreadsForPrompt`（记忆包）、`formatOpenThreadsForOutline` / `readerKnownOpenThreadTitles`（续排 / 摘要）全部过 `isReaderKnownThread`，该判定对 `kind === "dark"` 且未显式标可见性的旧数据也归入仅作者；`destinationNote` 无任何注入点；`formatVolumeMemory` / `previousVolumeEnding` 注入的出卷快照来自账本 / 作者改定，不是真相层；批量摘要工具的 openThreads 过滤同样排除 author_only 与 dark。
4. **文档点名的三处旧泄漏**：按拍契约暗线段（已删 + 测试反转断言）、续排不过滤可见性（已过滤）、正文注入 endingNote（已删 + 测试）——全部实锤堵住。
5. **暗线拦 AI 的唯一通道**是作者手写禁令进契约禁写清单，以「禁止写：」注入——与红线「不能以剧情内容形式注入、哪怕附带不得泄漏指令」一致。

## 四、「每天打开会怎么走」走查

按落地文档第一节逐步对照代码动线：

1. **打开项目** → 有大纲落正文页，顶部今日状态栏「未审 N 章 · M 条伏笔悬置超期」，并自动选中最早未审章。✅
2. **审未审章** → 右侧审阅侧栏自动展开：契约、账本现状与声音样本（可选人物本地抽台词）、摘要，与正文同屏三遍读。✅
3. **点「定稿…」** → 四步走完（或显式跳过）才能标已审；过账本一步确认前提议不入账、不进下一章记忆包；过伏笔可就地推进 / 回收 / 补记。✅
4. **未审清零后** → 状态栏伏笔超期入口直达伏笔板。✅
5. **点「写下一章」** → 有未审先弹提醒（可仍要写）；然后进本章契约：目标过时就地改并存回大纲、钩子、出场、时间地点、只读账本、全书禁写自动带入 + 本章增补、上章结尾折叠。「要写什么」空则生成禁用；「不能写什么」空须点「本章确无禁写」。✅
6. **生成后** → 皮肉错局部改（改写 / 续写工具在）、骨头错回契约补禁令重生成（契约视图可再进）。⚠️ 注意：手动改写 / 续写不带禁写清单（遗留 2），骨头错重生成必须走「按契约生成」那条才受禁令约束。
7. **近卷尾** → 状态栏「快到卷尾了 · N 条伏笔未定去向」，定稿触发完卷自动弹过卷向导，冻结四样落到卷上，续排新卷前弧线 / 出卷局面为空会先提醒。✅

**主链无卡点**；两处小坎是第 6 步的辅助路径禁令失效（遗留 2）和排大纲时结局方向勾选无效（遗留 1），都不在每日必经动线上。
