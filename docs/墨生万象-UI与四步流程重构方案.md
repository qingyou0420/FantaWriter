## 〇、一段话结论

产品从「幻想作家 / FantaWriter」更名为「**墨生万象 / Inkborne**」，视觉从"深红仪表盘"转向"松绿·纸色·金线"的文学书房气质。长篇工作区由「驾驶舱 / 大纲 / 织卷 / 书稿」四页签改为「**书房**（连载书房）+ **问心 → 研墨 → 织卷 → 落笔** 四步」；短篇映射为「创作书房 + 问心·织卷·落笔」三步精简版。左侧栏最顶端新增「作者信息」与「在创书目封面墙」。所有硬闸（G1 写前预检、卷纲锁定、每批 10 章确认、正典 diff 人闸、章审稿）**语义不变，只改归属与呈现**。原来散落在五处的「落墨」按钮收敛为每页至多一个主 CTA；「删除书籍」等危险操作移出页头，进入设置抽屉的"危险区"。

## A. 现状问题清单（对照三张截图）

编号规则：A1x 驾驶舱、A2x 大纲、A3x 书稿、A0x 全局。每条注明"证据 → 影响 → 处置去向"。

### A0 全局

- **A01 「织卷」一词三义。** 顶栏页签「织卷」是书内聊天（`BookWorkspaceNav.tsx` L36–59 `id:"chat"` label 织卷）；大纲页按钮「织卷·下一批」是排章；书稿页「织卷·规划下一章」是 planner。→ 用户无法建立"织卷 = 排纲"的稳定心智。→ 处置：织卷只指第三步；聊天改名「对谈」；「织卷·规划下一章」删除（B.3、C.3）。
- **A02 「落墨·写下一章」出现在 5 处。** 驾驶舱、大纲页「落墨·写这一章」、书稿页头、Dashboard 卡片、侧栏书菜单。→ 主 CTA 失焦，任一处被闸时其他处同样被闸但提示不一致。→ 处置：只保留书房"今日一笔"与落笔页两处（C.4）。
- **A03 入口不一致。** 侧栏点书名进「书稿」（`Sidebar.tsx` L228–238 `nav.toBookSettings`），Dashboard 点卡进「驾驶舱」（`Dashboard.tsx` L433 `nav.toBook`）。→ 处置：一律进书房。
- **A04 面包屑与页签名不符。** 书稿页面包屑显示「书籍设置」（`t("book.settings")`），页签却叫「书稿」。→ 处置：落笔页面包屑「落笔」，设置进抽屉。
- **A05 工程语汇泄漏到作者界面。** `Objective:` / `Key Results:` / `HOO3` / `H011` / `critical` / `[severity]` / `G1` / `audit-failed` 等原样展示。→ 处置：D 章"禁用清单"+ 文案映射表。
- **A06 顶栏「首页 / 幻想作家」是一颗按钮，与侧栏「我的创作」功能重叠**；且侧栏被测试要求不显示品牌（`branding-chrome.test.ts`），导致品牌无固定落点。→ 处置：品牌落在侧栏最底部一行小字 + 关于页；顶栏改为纯面包屑。
- **A07 字体在线加载。** `index.css` 用 Google Fonts CDN，Electron 离线时回落系统字体，文艺感全靠 Instrument Serif（拉丁字形，对中文无效）。→ 处置：本地打包中文衬线字体（D.2）。
- **A08 状态双轨。** `book.status` 由作者手动在下拉框选（大纲中/进行中…），与真实进度（真相文件是否齐、卷纲是否锁）无关，可互相矛盾。→ 处置：四步阶段由文件事实推导，`status` 只保留 paused/completed/dropped 三个人为标记（C.0）。

### A1 驾驶舱（截图 1）

- **A11 标题即摘要。** 「下一章」卡片大字标题是整句章提要（`第1章·倒叙冷开(见开篇技法)→落回书院春日…`），下方 oneLine 再重复一遍。根因是 `volume_map.md` 中章条目"标题=提要"未拆分（见 A22）。→ 处置：织卷输出契约要求「短题（≤12 字）+ 提要」两字段；书房卡片标题只显示短题，无短题时显示「第 N 章」。
- **A12 卷目标卡片是 OKR 原文倾倒。** 大段 Objective/Key Results，含内部钩子编号。→ 处置：卷卡片只显示卷名、进度（1/38）、「本卷要抵达」一句；展开后才看全文。
- **A13 「带病续写」常驻可见。** 默认暴露绕闸选项，与"不满足即拒绝"的硬闸精神相悖。→ 处置：仅当 G1 原因含"上一章未通过"时，在原因列表下方出现该选项（C.4）。
- **A14 底部「打开大纲」「织卷」两按钮同一目标**（都 `nav.toOutline`）。→ 处置：删除，由四步进程条承担导航。
- **A15 无阶段感。** 书是"大纲中"却不显示"卷纲已锁、细纲 38/260、正文 0"，作者不知道自己在哪一步、下一步做什么。→ 处置：书房顶部四步进程条 + 「今日一笔」卡（E.2）。
- **A16 落墨按钮与"下一章"卡分离**，中间隔着卷目标卡，视线断裂。→ 处置：「今日一笔」卡内含主 CTA。

### A2 大纲（截图 2）

- **A21 左树把非卷标题当卷。** 「第一卷分章事件清单（可在其上补合…）」「第一卷·节点A」「第一卷·节点B」「第二卷:以"德者掌兵"…」被解析为卷，统计出「19 卷 · 38 章」而实际 7 卷。根因：`volume-map-tree.ts` 以 Markdown 标题层级切卷，architect/织卷输出的说明性标题混入。→ 处置：织卷"锁定卷纲"输出契约收紧（卷标题格式 `## 第N卷 卷名（第a–b章）`，其他标题一律不进树）；解析器对不匹配卷格式的标题归入"备注"节点并折叠；提供「整理卷纲」一键修复（C.3）。
- **A22 章节点为范围（第 4–5 章、第 6–9 章、第 10–14 章）。** 一节点多章，无法逐章落墨。根因同 A21：粗纲被当细纲。→ 处置：树区分「粗纲区间」（灰色、不可落墨）与「细纲章」（可落墨）；织卷下一批负责把区间展开为逐章。
- **A23 右详情"标题"输入框装整句，"提要"为空。** → 处置：保存时若标题 >20 字且提要为空，自动拆分（首个「，。；→」前为题）并提示。
- **A24 动作过多且重复：** 顶部「织卷·下一批」「新增一章」，详情区「保存」「落墨·写这一章」「织卷·下一批」。→ 处置：织卷页只有一个主 CTA（锁定卷纲 / 下一批）；「落墨·写这一章」从织卷页移除（作者在落笔页写）；「新增一章」进节点右键/「…」菜单。
- **A25 卷层无详情。** 点卷名只展开，看不到卷 OKR、章范围、是否已锁。→ 处置：卷详情面板（E.5）。
- **A26 目标章数 260 与已规划 38 章无对照。** → 处置：织卷页头显示「已排 38 / 目标 260 章 · 已锁 1 / 7 卷」。
- **A27 筛选"全部/待写/已写"是落笔视角**，在排纲阶段意义弱。→ 处置：改为「全部 / 仅粗纲 / 待细化 / 已细化」，"已写"状态用左侧小点表示。

### A3 书稿（截图 3）

- **A31 危险操作紧邻主 CTA。** 页头一行：落墨·写下一章 / 仅草稿 / 审查:自动 / **删除书籍**（红）。误触即毁书。→ 处置：删除进「设置抽屉 → 危险区」，二次确认输入书名。
- **A32 「仅草稿」「审查:自动」是写作模式设置，却做成与主 CTA 同级的按钮。** → 处置：落笔主按钮做成分裂按钮（主：落墨·写下一章；下拉：仅起草不审 / 审查模式：自动|手动）。
- **A33 工具行 8 项混装导航与动作：** 真相文件（导航）/ 数据分析（导航）/ 质量评估（动作）/ 归并记忆（动作）/ 重修设定（动作）/ 织卷·规划下一章（动作、与织卷重复）/ 组装（动作、语义不明）/ 导出组（select+checkbox+两按钮）。→ 处置：真相文件→研墨页；重修设定→研墨页次级动作；织卷·规划下一章→删除；质量评估/归并记忆/数据分析/组装→书房「更多工具」抽屉；导出→落笔页头「导出」下拉。
- **A34 书籍设置（每章字数/目标章数/状态）与章节表同页。** 设置是低频，章节表是高频。→ 处置：设置进抽屉。
- **A35 空态错误。** 书还在大纲阶段，落笔页却显示「暂无章节，点击写下一章开始」；此时"写下一章"其实被闸。→ 处置：空态按阶段文案（C.4 空态表）。
- **A36 「下一章 1 · 可以落墨」条 + 带病续写 与驾驶舱重复。** → 处置：落笔页保留一条「下一章」状态行；带病续写规则同 A13。
- **A37 审稿队列原样输出 `[critical] 第3 · continuity: …`。** → 处置：中文严重度（须处理 / 建议）+ 类别中文映射。

### C.0 阶段推导（不再手选）

### D.2 字体层级（离线打包，替换 Google Fonts `@import`）

| 角色 | 字体 | 打包方式 |
|---|---|---|
| 标题/书名/章题（中文） | **霞鹜文楷 LXGW WenKai**（OFL）或 **Noto Serif SC**（OFL） | woff2 子集放 `packages/studio/public/fonts/`，`@font-face` 本地引用；`third_party/` 记录许可证 |

### D.3 卡片与留白

- 卡片 = "纸页"：`--card` 底、1px 发丝边、圆角 12、无阴影或 `--shadow-soft`；禁用 `shadow-lg shadow-primary/20`、`hover:scale-105`。
- 页面最大宽 880，主列单栏；织卷页例外（树 280 + 详情）。
- 区块之间用 32px 留白 + 可选金色 24px 短横线，而不是一个个描边盒子。
- 进程条：细线连接的四个圆点，完成态实心松绿、当前态描边 + 金点、未开始空心。
- 图标：lucide 1.5px 线宽，16px，颜色随文字；主 CTA 用羽毛（Feather）而非闪电（Zap）。
- 动效：仅 fade/slide 150–200ms；写作中用"墨点呼吸"一颗，不用旋转 spinner 铺满。

### D.4 禁用"工程仪表盘感"具体清单

1. 禁止英文全大写追踪字距小标签。
2. 禁止原样输出内部编码（H003、G1、critical、audit-failed、continuity）；一律走中文映射表（`lib/copy-map.ts`：severity → 须处理/建议；category → 连贯性/人物/时间线/世界规则/文风）。
3. 禁止一行 > 3 个按钮；超出收进「⋯」。
4. 禁止红色按钮出现在页头；危险操作只在抽屉"危险区"。
5. 禁止 badge 计数堆叠（"待确认正典 3 条" 用一句话 + 链接）。
6. 禁止 `alert()`；改用 toast（shadcn sonner）或内联提示。
7. 空态必须有一句"文学式"引导 + 一个下一步按钮，不出现"暂无数据"。
8. 页面副标题不用"·"连缀技术说明（如「连载驾驶舱 · 今天写哪一章」），改为一句话人语（「今天，写第十二章」）。
