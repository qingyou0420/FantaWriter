# 墨生万象（Inkborne）· 书房与四步独立页导航方案

> 状态：**规划文档，本 PR 只含本文件，不改业务/UI 源码，不 bump 版本，不改 appId / 安装包名。**
> 基线：`master` @ v2.1.2（`60e7a38`，含 #101「首页侧栏抛光与问心抽屉修复」）。
> 上位文档：`docs/墨生万象-UI与四步流程重构方案.md`（下称「UI 方案」）、`docs/墨生万象-首页与侧栏收敛方案.md`（下称「收敛方案」）、`docs/墨生万象-首页侧栏抛光与问心抽屉方案.md`（下称「抛光方案」）。三份文档里「问心 = 右侧抽屉」的条文**全部被本文替代**，修正点集中列在 H 章。
> 用户结论（v2.1.2 试用后）：**否决抽屉模型**。问心是独立页面；问心、研墨、织卷、落笔是四个独立页面；书内左侧只留一个【书房】按钮；右侧是四个页面入口。

---

## 〇、一段话结论

v2.1.0 把书内聊天做成 420px 右侧抽屉叠在书房之上，v2.1.1 把「问心」步定义为「开抽屉」，v2.1.2（#101）修了抽屉里 `ChatPage` 被 `BookSidebar` 挤没的缺陷——但用户的心智模型从来不是「书房 + 抽屉」，而是「**一本书 = 一个书房总览 + 四个独立工作页**」。本文把书内导航改成**五页平铺**：`#/book/:id`（书房总览）、`/ask`（问心）、`/ground`（研墨）、`/weave`（织卷）、`/write`（落笔），任何时刻只有一页在屏上；书内 chrome 变成一行——**左【书房】｜右 问心·研墨·织卷·落笔·⋯**，当前页高亮；各页头部的「首页 / 《醉词》 / 研墨」面包屑删除（回首页走顶栏「首页」）。问心页复用 `#/book/new` 的整页布局（左 `ChatPage mode="book"`，右侧故事卡栏），侧栏「问心记录」点会话直接进该书问心页并加载该会话。`App.tsx` 的 `book-talk-drawer`、`bookChatOpen`、`closeAskDrawer`、`onToggleChat`、`chatOpen`、`toBookChat` 全部删除；`#/book/:id/chat` 重定向到 `/ask`。四步状态机、硬闸、后端 API **一律不动**。建议一个小 PR（`P0-5 书房与四步独立页`），不 bump。
