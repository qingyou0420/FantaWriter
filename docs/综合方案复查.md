## 六、非阻塞小瑕疵（不必为合入返工，记档即可）

1. **旧库探测的降级窄缝**：`oldIdbExists()`（storage.ts:88–98）在浏览器不支持 `indexedDB.databases()` 时退化为「旧 localStorage 项目键存在即真」，此时 `readIdbProjects(OLD_IDB_NAME)` 的 open 仍会建出旧库。只影响「老浏览器 + 确有旧数据」的存量用户迁移路径；全新用户两条路径都不建库（有测试兜着），主流 Chromium/Electron 均支持 `databases()`。
2. **theme.ts 残留旧品牌键**：`THEME_STORAGE_KEY = "h-novelist:theme"` 等常量与 flag 控制的双写仍在（theme.ts:7–12、93–96），默认 `brandRenameComplete=true` 不双写、仅读回退。方案 P1-2 点名的是 storage 层（已清），这属未点名的同类残留。
3. **CSS 死代码**：`globals.css:331` 的 `.mode-badge-erotic` 无引用，纯样式残留。
4. **P1-1 快照对比**：迁移前后 assemble 输出没有留下字面快照文件，以 `assemble.test.ts` 的结构断言（priorBlock 注入次数与位置、篇幅硬区间、名片降级等）替代，保护力足够。
