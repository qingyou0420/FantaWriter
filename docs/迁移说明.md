# FantaWriter / 幻想作家 1.0.0（常规独立版）

本仓是公开的常规小说独立版，不是其它写作台的兼容升级包。

## 安装与更新

| 用途 | 文件 |
|------|------|
| Windows 安装包 | `FantaWriter-Setup-*.exe`（1.0.0 当时发布为 `Fantasy-Writer-Setup-1.0.0.exe`） |

桌面更新**默认读本仓 GitHub Releases latest**（`qingyou0420/FantaWriter`，公开仓，无需令牌）。云端检查失败时仍扫描：`FantaWriter-Updates`、`Fantasy-Writer-Updates`、`%APPDATA%\fantawriter\updates`、桌面、下载、文档。

`package.json` 的 `name` 为 `fantawriter`，`appId` 为 `com.fantawriter.app`，因此 Electron `userData` 是 `%APPDATA%\fantawriter`。

## 本机数据

| 用途 | 本版键 |
|------|--------|
| 项目 IDB | `fantawriter` |
| 项目 LS | `fantawriter:projects` |
| 标签/文风库 | `fantawriter:libraries`（仅常规类型标签） |
| 主题 / 偏好 | `fantawriter:theme` / `app-prefs` |

桌面端读 `%APPDATA%\fantawriter\config.env`。文件头注释为 FantaWriter，键名仍是 `DEEPSEEK_API_KEY` 等。不要把 `.env` 或密钥提交进仓。

## 功能边界

- 只有常规小说：人物、大纲、分卷、原作焕新、写进仓库、正文生成。
- 原作焕新按用户粘贴的原文与锁定设定工作，不写死任何一部原作。
