# 从 H-NoveList 1.8.1 迁到 Fantasy Writer 2.0

## 安装包

| 客户端 | 应使用的文件 |
|--------|----------------|
| 新装 / 已是 Fantasy Writer | `Fantasy-Writer-Setup-2.0.0.exe` |
| 库存 1.8.1（旧更新器只认 `H-NoveList-Setup-*.exe`） | `H-NoveList-Setup-2.0.0.exe` |

两份是**同一二进制**，只是文件名不同。带空格的 `Fantasy Writer-Setup-2.0.0.exe` **无效**，更新器不会识别。

桌面更新**默认读 GitHub Releases latest**（`qingyou0420/fantasy-writer`）。私有仓请在设置里填本机 GitHub 令牌。云端检查失败时仍扫描：`Fantasy-Writer-Updates`、`H-NoveList-Updates`、`%APPDATA%\h-novelist\updates`、桌面、下载、文档。

`package.json` 的 `name` 仍为 `h-novelist`，因此 Electron `userData` 仍是 `%APPDATA%\h-novelist`，`config.env` 不必搬家。

## 数据键

| 资源 | 2.0 主键 | 旧键（只读回退一轮） |
|------|----------|----------------------|
| 项目 IDB | `fantasy-writer` | `erotic-novel-studio` |
| 项目 LS | `fantasy-writer:projects` | `erotic-novel-studio:projects` |
| 标签/文风库 | `fantasy-writer:libraries` | `erotic-novel-studio:tag-library` / `style-library` |
| 主题 / 偏好 | `fantasy-writer:theme` / `app-prefs` | `h-novelist:theme` / `app-prefs` |

2.0 **不再写入**旧键。首次启动会把旧数据读进新库。请尽快用首页「下载完整备份」留一份 `fw-backup-*.json`。

旧备份文件名 `ens-backup-YYYY-MM-DD.json` 仍可用修复工具 `importFullBackup` 导入一次（按项目 id 去重，已有项目跳过）。

## 项目字段

旧项目（无 `writingBoard`）一律视为 **色情台** + schemaVersion 2 + 默认卷 `第一卷`（id `${projectId}:vol:1`）。

- 常规新书：类型标签、无色情尺度、无行为标签库。
- 色情旧书：尺度、行为标签、`more_erotic` / `less_erotic` 均保留。
- 看板切换只过滤列表，**不会**改这本书的写作台。改台请用项目内「转换向导」（默认另存）。

## API 配置

桌面端仍读 `%APPDATA%\h-novelist\config.env`。文件头注释改为 Fantasy Writer，不影响键名（`DEEPSEEK_API_KEY` 等）。
